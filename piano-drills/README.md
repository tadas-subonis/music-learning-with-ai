# Five-Minute Piano Drills

Printable practice drills for a beginner pianist working towards *The Scientist* (Coldplay),
*The Loneliest Girl* (Carole & Tuesday), lo-fi piano and simple electronic-music melodies.

**[Five-Minute-Piano-Drills.pdf](Five-Minute-Piano-Drills.pdf)**: 16 A4 pages, made for a black-and-white laser printer.

| Page | Content |
|---|---|
| 1 | Intro: how to use the drills, rules, drill map |
| 2 | Drill 1 – Count the Groove (rhythm, syncopation) |
| 3 | Drill 2 – The Major Scale |
| 4 | Sheet 2+ – Scale Sheet (exact notes of each key) |
| 5 | Drill 3 – Chord Staircase |
| 6 | Sheet 3+ – Chord Sheet (exact notes of each chord) |
| 7 | Drill 4 – Lazy Hands (inversions, voice leading) |
| 8 | Drill 5 – The Bass Engine |
| 9 | Drill 6 – Broken Chords |
| 10 | Drill 7 – Split the Beat (hands together) |
| 11 | Drill 8 – Lo-fi Colours (7ths, sus, add9) |
| 12 | Drill 9 – No Wrong Notes (pentatonic improvising) |
| 13 | Drill 10 – Build a Tune (motif to melody) |
| 14 | Drill 11 – The Big Five Progressions |
| 15 | Drill 12 – Chord Vocabulary |
| 16 | Song roadmap and progress log |

Each drill is a 5-minute daily routine with a level ladder, meant to be repeated for weeks.
The song pages give chord progressions only, no melodies.

## Sources

- `drills.lytex`: the document (LaTeX with embedded LilyPond music)
- `preamble.tex`: layout, boxes, keyboard diagrams, rhythm grids
- `build.sh`: rebuilds the PDF

Requires LilyPond 2.24+ and XeLaTeX (TeX Live). Run `./build.sh`.
